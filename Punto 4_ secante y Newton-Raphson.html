Punto 4: f(x) = 2·sen(x) − x

Métodos de la secante y Newton-Raphson, con cálculos iteración por iteración. Cambia los datos y se recalcula.

a) Puntos iniciales

b) Convergencia

  • La secante es un método abierto que no usa derivada: reemplaza f’(x) por la pendiente de la recta entre los dos últimos puntos.
  • Su orden de convergencia es superlineal, de aproximadamente 1.618.
  • Converge si la raíz es simple y la pendiente cerca de ella no es cero.
  • Falla si f(xi−1) = f(xi), porque se divide entre cero.

c) Código en Java

public class Secante {

    // f(x) = 2 sen(x) - x
    static double f(double x) {
        return 2 * Math.sin(x) - x;
    }

    public static void main(String[] args) {
        double xAnt = 1.0;          // x0
        double xAct = 2.0;          // x1
        double tolerancia = 0.005;  // error aproximado en %
        int maxIter = 50;

        String linea = "-".repeat(100);
        System.out.println(linea);
        System.out.printf("%-10s %-14s %-14s %-14s %-16s %-16s%n",
                "Iteracion", "x(i-1)", "x(i)", "x(i+1)", "f(x(i+1))", "Error aprox (%)");
        System.out.println(linea);

        for (int i = 1; i <= maxIter; i++) {
            double fAnt = f(xAnt);
            double fAct = f(xAct);

            if (fAnt - fAct == 0) {
                System.out.println("Division entre cero, el metodo se detiene.");
                break;
            }

            double xSig = xAct - fAct * (xAnt - xAct) / (fAnt - fAct);
            double error = Math.abs((xSig - xAct) / xSig) * 100;

            System.out.printf("%-10d %-14.7f %-14.7f %-14.7f %-16.4e %-16.6f%n",
                    i, xAnt, xAct, xSig, f(xSig), error);

            if (error <= tolerancia) {
                System.out.println(linea);
                System.out.printf("Raiz aproximada: %.7f en %d iteraciones%n", xSig, i);
                break;
            }

            xAnt = xAct;
            xAct = xSig;
        }
    }
}
